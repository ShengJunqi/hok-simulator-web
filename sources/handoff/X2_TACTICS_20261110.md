## 接口

```python
from hokmodel.simulator.tactics import (
    load_rules, match_rules, format_rule_cards, explain_with_rules,
)

rules = load_rules()                 # 100 条，全部 candidate / active_by_default=False
dragon_rules = load_rules(topics="龙团")  # 12 条，只查阅，不认定现场满足条件

state = {
    "phase": "early",
    "topics": "开局",
    "tactic_checks": {
        "T2-O01": {"trigger": True, "counterexample": False},
    },
}
assert match_rules(state, "early") == []  # 默认关闭，且不读取 JSONL
cards = match_rules(state, "early", enabled=True)
print(format_rule_cards(cards))

event = {
    "event_id": "x2.synthetic.example",
    "kind": "preparation", "team": "blue", "at": 0, "phase": "early",
    "details": {"reason": "调用方声明敌方存在入侵或偷野组合"},
}
text = explain_with_rules(event, state, enabled=True)
# 缺省/False：与 commentary.explain_event(event) 完全相同。
# True：事实 → 依据 → 规则卡；事实和依据只复用原解说，不从战术检查补数值或事件。
```

触发条件和反例在原库中是自然语言，尚无可验证的自动状态谓词。本接口采用**调用方显式核对**：`tactic_checks[id].trigger=True` 声明完整触发条件满足，`counterexample=False` 声明反例/失效边界未发生。缺省、`null`、触发为假或反例为真均不返回该卡。只给“龙团”、入侵关键词、经济领先、敌人消失等零散信息不会自动命中；不凭关键词翻译战术结论，不读取隐藏世界状态。条件声明本身也不是游戏事实或有效性证明，调用方负责观测与时效。

`match_rules(state, phase, *, enabled=False, topics=None, rules=None)` 返回 JSON 可序列化的字典列表，保持 JSONL 顺序。每张卡完整保留原字段，另附 `match.phase/basis/trigger/counterexample/path`；依据路径指向 `state.tactic_checks[id]`。返回值与调用方对象独立，修改规则卡不会修改输入或磁盘文件。

`phase` 可用 11 个中文主题（含 `BP`），或者 `draft/opening/early/mid/late/storm` 与现有 `Phase` 枚举。主题直接查询该类；`draft` 粗筛 BP/心态/指挥；`opening/early` 粗筛非 BP；其余局内阶段粗筛非 BP、非开局。其他主题跨局内阶段保留，例如 S01 也描述前期。此为研究检索口径，不是从视频时间推导的阶段定律。`topics` 或 `state.topics` 再取交集，显式参数优先；空列表表示不选主题。`state.phase` 若存在，必须与请求阶段一致。

`explain_with_rules(event, state, *, enabled=False, phase=None, topics=None, rules=None, program=None, context=None)` 默认保持原字符串；开启后沿用原事实、理由与缺参说明，再附候选卡。阶段依次采用显式参数、事件阶段、状态阶段；无阶段或阶段冲突报错，不从事件名称或视频秒猜阶段。`program/context` 沿用原解说的身份补充规则。不会改变事件、状态、抽样、账本或概率。

`load_rules(path=None, *, topics=None)` 默认文件相对源码位置定位，不依赖工作目录；默认库必须恰好覆盖 100 个合法唯一 ID。显式路径允许同一 schema 的非空子集。所有记录先验证再筛选；格式错误、重复 JSON 键/ID、空来源、非法主题、非整数/负来源秒、来源链接不一致、非候选/默认启用/伪核验状态、擅补游戏时间或补丁等均拒绝。文件不存在直接报错，不悄悄返回空库。无缓存、无写盘、无概率字段注入。

## 示例规则卡

以下条件与事件仅为调用示例，不代表观察到一场比赛：

> **T2-O01 · 开局**：先检查双方一级入侵和偷野能力，再决定刷野起点及队友看守的入口。  
> 触发：开局加载至第一轮野区；敌方有入侵或偷野组合。  
> 反例：机械沿用同一开野路线，可能让无人看守的另一半区被偷；守不住时要预备交换。

> `confidence=medium`；`status=candidate`；`active_by_default=False`。  
> 匹配依据：调用方声明完整条件满足、反例未发生；未经验证。  
> 版本风险：`hero_patch`；HOK：`mechanic_not_transferable_without_verification`。
