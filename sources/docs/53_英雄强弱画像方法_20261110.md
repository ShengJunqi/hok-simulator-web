# 英雄强弱画像方法（2026-11-10）

本稿及配套 JSON 全部为 CN 研究候选/待核，不是当前版本强度表，不得直接进入默认模型、阶段档分或冻结参数库。Jason 口径：月爱（UP 月爱）相对最权威，指强弱评价；官方权威用于确认调整事实，两者分工不同。

## 1. 从调整推断局部机制

每条先记录英雄、技能、对象、触发条件、出装/等级、分路/分段、服务器环境、方向、旧值/新值及生效日，再解释。任一关键字段未核则填 `unknown`，原述放在候选证据层，不补数值或技能编号。

- 加强某机制 → 提出“调整前该机制可能不足/受限”的弱点假设。若官方同时明确痛点，支持更直接；单纯上调只能说明设计者提高了该项收益。补偿其他削弱、鼓励另一玩法、降低操作门槛，也可能造成加强。
- 削弱某机制 → 提出“调整前该机制可能偏强/收益过高”的强点假设。需要定位具体收益，不能把英雄整体、所有分段或削弱后的状态都判强；也可能只是资源重分配。
- `adjust` 必须拆方向：基础伤害下降与属性加成上升分开；对兵与对野分开；减伤惩罚降低实际是输出提高。未说方向的“优化”仍为 unknown。
- UI 提示只推信息可读性；bug 修复只推特定异常及可靠性。未来意向、标题“史诗级”、条件性答复没有落实方案，不能作为补丁事实。传闻中的明确痛点可单列“作者反馈待核”，不能借传闻反推既成调整。
- 旧弱点经加强可能缓解但未必解决；旧强点经削弱可能仍强。当前结论还需同服同版本的月爱评价、可比统计和机制核验。空数组表示无足够证据，不表示没有强/弱点。

例：王昭君水域移速收益必须带“有护盾＋水域”条件；清线改善涉及攻击冰冻单位，不能泛化为全图移速或无条件群伤。敖隐一技能伤害/爆发移速下降与二、三技能伤害提高并存，整体净效果 unknown。诸葛亮对野伤害减免减少为刷野方向加强，对兵加成减少为清线方向削弱。

## 2. 权威与证据权重

采用分通道的顺序权重，不把视频条数或来源声望换成战力分：

| 通道 | 优先顺序与边界 |
|---|---|
| 调整事实 | 已核官方公告/实服记录最高；官方视频原音画次之；创作者转述仅候选；传闻无事实权重。官方上传身份不等于补丁已生效。 |
| 强弱评价 | 同版本、同分路/分段且已核原话的月爱优先；其他创作者及官方设计说明补充语境。官方设计目标不能覆盖月爱实战评价，月爱也不能替代公告旧值/新值。 |
| 统计背景 | 苏苏接口观测独立保留；样本量、分段、时间窗、分路或补丁不明时，不与月爱榜单直接平均，不转因果强度。 |

权威、抽取清晰度、适用性分开记录。月爱是评价优先来源，但 OCR 错字、画面姓名绑定及秒码未核仍为低可信候选；`TO.5` 不改成 `T0.5`。榜位不是升降，视频发布日期不是数据日期。来源矛盾保留双方及缺口；不能用多条重复转述投票。

## 3. 时间衰减与版本敏感性

“近一年”检索窗定为 `(2025-11-10, 2026-11-10]`，按核实的 CN 生效日归档；跨界机制可另存起点快照。只知月日、发布日期或“本周五”不能判入窗。当前补丁输入没有完整生效日期，年度覆盖与年龄均 unknown。

候选研究规则：`d=2^(-天数/半衰期)`，强弱评价暂用45天、机制适用性暂用90天；均为方法假设，未校准，未对本批记录实际计算。评价以可核的数据快照/评价适用日计龄，机制以生效日计龄。日期不明则 d=unknown，不能当今天或零权重。历史调整事实不随时间变假，衰减的是它对当前画像的解释力。

先检查版本再谈衰减：同机制被重做、回调或覆盖，旧解释退出当前候选但保留历史；装备、地图、兵野、模式或分段变化触发复核。体验服与正式服分支隔离，预告不视为上线。可比较条件不成立时不计算综合分；细节需在同等级、同经济/装备、同目标与同触发条件下验证。机制方向最多导出情景假设，不能填胜率增幅。
